QSL-Karten-Generator

Paketquellen für Debian/Ubuntu (apt) und Fedora (dnf), 64-Bit-PC (x86_64).

Debian / Ubuntu

Debian 12 oder neuer, Ubuntu 22.04 oder neuer.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @BASE_URL@/qsl-karten-generator.gpg | sudo tee /etc/apt/keyrings/qsl-karten-generator.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/qsl-karten-generator.gpg] @BASE_URL@/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/qsl-karten-generator.list
sudo apt update
sudo apt install qsl-karten-generator

Fedora

sudo curl -fsSL -o /etc/yum.repos.d/qsl-karten-generator.repo @BASE_URL@/qsl-karten-generator.repo
sudo dnf install qsl-karten-generator

Aktualisieren und entfernen

Neue Fassungen kommen mit dem normalen Systemupdate (sudo apt upgrade bzw. sudo dnf upgrade). Entfernen mit sudo apt remove qsl-karten-generator bzw. sudo dnf remove qsl-karten-generator. Einstellungen und Cache liegen in ~/.config/qsl-karten-generator/ und bleiben dabei erhalten.

Andere Systeme

AppImage für andere Linux-Distributionen, Windows und macOS gibt es unter Releases.
